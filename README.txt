Coach Bobby Academy — First Prototype

How to use:
1. Open index.html in a modern browser.
2. Tap Play.
3. Watch the 11v11 animation freeze.
4. Answer the question.
5. Tap Next lesson.

This prototype includes:
- Full 11v11 field
- Player labels attached to moving players
- Play, pause, reset
- 3 starter lessons
- Explanations
- Coach IQ score
- Responsive mobile layout
