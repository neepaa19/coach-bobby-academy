# V8 Specification

## Goal

Transform Coach Bobby Academy from a prototype into a true tactical learning platform.

---

# Tactical Engine

- Smooth defensive shifting animations
- Smooth attacking support movement
- Ball and players animate together
- No teleporting

---

# Decision Engine

- Hold player to preview pass
- Tap player to commit pass
- Automatically determine best pass type
- Show estimated pass confidence
- Explain every score

---

# Pass Analysis

Display:

- Pass confidence
- Receiver separation (exact yards)
- Starting separation
- Defender closing distance
- Effective separation
- Pass distance
- Distance to goal
- Progress toward goal
- Lines broken
- Tactical explanation

---

# Learning

- Multi-pass scenarios
- Adaptive difficulty
- Multiple correct solutions
- Better "Why" explanations

---

# Knowledge

Begin foundation for:

- Coaching Library
- Coach Repository
- Player Repository

---

# Objective

Every feature should teach users WHY a decision is correct instead of simply telling them the answer.
