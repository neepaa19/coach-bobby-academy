# Decision Engine

## Purpose

Every tactical decision should be evaluated using explainable football logic.

The user should always understand WHY one option scores higher than another.

---

## Pass Confidence Score (0–100)

The score is calculated from measurable factors.

### Factors

1. Receiver separation
2. Passing lane openness
3. Defender pressure
4. Pass distance
5. Defensive compactness
6. Direction of play
7. Number advantage near receiver
8. Tactical objective alignment

---

## Output Example

Pass: LCB → RCM

Confidence: 82%

Why:

+18 Receiver separation (11.8 yd)

+16 Passing lane mostly clear

+10 Advances toward weak side

-8 Medium pressure

-6 Longer pass (26 yd)

-4 Compact defensive block

Estimated receiver space:
11.8 yd

Recommended pass:
Ground pass

---

## Principles

Every score must be explainable.

No random numbers.

Every bonus and penalty should reference a measurable football concept.

If two passes are nearly equal, both should be presented as viable options.
